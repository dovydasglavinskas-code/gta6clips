Privacy Policy

Last updated: 2026-11-18

This tool uses the YouTube Data API only to upload videos to the channel of the person who signs in. It requests the scope youtube.upload and nothing else.

No personal data is collected, sold or shared. The access token is stored only on the owner's own computer and is never sent anywhere except Google.

Access can be revoked at any time at myaccount.google.com/permissions.

The tool uses YouTube API Services; see the Google Privacy Policy.
